# Neo4j vježba

Ovaj projekt sadrži vježbu iz Neo4j graf baze podataka.

## Kako pokrenuti projekt

1. Otvoriti terminal u folderu projekta
2. Pokrenuti Docker:
   docker compose up -d
3. Otvoriti Neo4j Browser:
   http://localhost:7474
4. Prijaviti se:
   username: neo4j  
   password: vjezba2026

## Sadržaj repozitorija

- docker-compose.yml — pokretanje Neo4j okruženja
- queries.cypher — svi Cypher upiti iz vježbe
- screenshots/ — slike iz Neo4j Browsera
- ODGOVORI.md — teorijska pitanja
